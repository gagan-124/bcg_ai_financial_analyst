# BCG AI Financial Analyst - Rulebook

## Development Lifecycle
Every feature follows this strict 6-stage lifecycle:

1. **Think**
   - Deeply analyze requirements, edge cases, data structures, and architectural boundaries before writing code.
2. **Design**
   - Plan clean component interfaces, API contracts, schema models, and data flows.
3. **Document**
   - Update architecture docs, schemas, or implementation plans to reflect decisions.
4. **Build**
   - Implement the feature adhering strictly to TypeScript, Python, and project naming conventions.
5. **Review**
   - Run linters (Ruff, ESLint/TypeScript check), automated test suites, and type-checks.
6. **Lock**
   - Freeze the verified state, verify git clean status, and prevent scope creep.
